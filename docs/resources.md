## Recommended working tools

| Need | Suitable tool | Control note |
|---|---|---|
| Process mapping | diagrams.net, Visio or approved equivalent | Remove identifying process details before publication. |
| Spreadsheet analysis | Excel or Google Sheets | Use synthetic data and a documented data dictionary. |
| Dashboard | Power BI or Looker Studio | Define KPI source, owner and refresh logic. |
| Workflow automation | Power Automate or approved low-code tool | Include permissions, exception handling, audit and rollback. |
| Project coordination | Planner, Trello, GitHub Projects or approved system | Avoid storing confidential executive records publicly. |
| Documentation | Markdown, Word, Google Docs or SharePoint | Apply versioning, access and retention controls. |

## Source verification checklist

Before using an online tutorial:

- Prefer official product documentation or recognised training providers.
- Check publication or last-updated information.
- Confirm the tutorial matches the current product interface.
- Never paste credentials, private records or production data into a tutorial environment.
- Record the source URL and what was learned in the evidence log.
