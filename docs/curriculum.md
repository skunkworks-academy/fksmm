# Learning Curriculum

| Curriculum area | Learning outcomes | Required evidence |
|---|---|---|
| Business process improvement | Map processes, identify constraints, define controls and measure improvement. | Process map, SOP, improvement backlog and before/after metric. |
| Data analysis | Clean data, validate quality, analyse trends and explain business implications. | Analysis workbook and data-quality log. |
| Operational reporting | Define KPIs, build dashboards and write executive commentary. | Dashboard, KPI dictionary and one-page monthly brief. |
| Low-code automation | Design workflows with approvals, permissions, exceptions, logging and rollback. | Prototype, test plan, exception log and user guide. |
| AI-enabled productivity | Use AI tools with verification, privacy and quality controls. | Prompt library, verification checklist and productivity measure. |
| Project and change coordination | Define scope, stakeholders, risk, communication and adoption. | Charter, RAID log, communication plan and retrospective. |
| Leadership and strategic support | Frame decisions, prioritise work, facilitate reviews and communicate value. | Decision brief, presentation and leadership reflection. |

## Module assessment model

Each module is assessed across five dimensions:

| Dimension | Weight |
|---|---:|
| Conceptual understanding | 20% |
| Practical functionality | 25% |
| Documentation and communication | 20% |
| Governance, privacy and control design | 20% |
| Reflection and response to feedback | 15% |

**Pass:** 70%  
**Distinction:** 85%  
**Critical failure rule:** evidence containing confidential or unauthorised information cannot pass until corrected.

## Delivery format

- Instructor demonstration
- Guided lab
- Independent applied build
- Knowledge check
- Evidence review
- Mentor feedback
- Career-translation note
