# Applied Portfolio Projects

## Project 1 — Executive Operations Control Centre

**Problem:** priorities, meetings, decisions and actions are fragmented across tools.  
**Outputs:** synthetic executive dashboard, decision log, action tracker, meeting cadence and access model.  
**Success measure:** improved action visibility and fewer overdue items in the simulated workflow.

## Project 2 — Process Improvement and SOP Pack

**Problem:** a process has unclear hand-offs, duplicated effort or weak exception handling.  
**Outputs:** current/future process map, SOP, RACI, risk register and improvement backlog.  
**Success measure:** clear baseline and approved future-state design.

## Project 3 — Controlled Workflow Automation

**Problem:** a recurring approval, onboarding, expense, supplier or document process relies on manual reminders.  
**Outputs:** automation prototype, permissions, exception path, test cases, rollback and user guide.  
**Success measure:** reduced manual touches and complete critical-test pass rate using synthetic data.

## Project 4 — Operational and Financial Dashboard

**Problem:** leaders lack a concise view of cost, service, workload or performance.  
**Outputs:** clean dataset, KPI dictionary, dashboard, monthly narrative and data-quality log.  
**Success measure:** traceable metrics, clear assumptions and decision-ready commentary.

## Project 5 — AI-Assisted Executive Briefing System

**Problem:** briefings and recurring reports consume time and vary in quality.  
**Outputs:** prompt patterns, source-verification checklist, briefing template, privacy rules and time comparison.  
**Success measure:** demonstrated time saving without unsupported claims or sensitive-data exposure.

## Publication standard

Every public project must use sanitised evidence, describe the privacy boundary, state limitations and translate the result into one CV achievement and one interview story.
