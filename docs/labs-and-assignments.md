# Labs, Tutorials and Assignments

## Lab 1 — Synthetic Operations Dataset

Create a 200-row synthetic dataset for tasks, owners, due dates, status, costs and service categories. Apply validation, quality checks, lookups, pivot analysis and charts.

**Evidence:** workbook, data dictionary, quality log and five business insights.

## Lab 2 — Process Map and SOP

Map a recurring executive-support, supplier, expense, document or project-coordination process. Include actors, hand-offs, exceptions, controls and future-state changes.

**Evidence:** current-state map, future-state map, RACI and two-page SOP.

## Lab 3 — Project Coordination Pack

Create a mini transformation charter, stakeholder map, RAID log, work breakdown, meeting cadence and status report.

**Evidence:** complete project pack and five-minute status briefing.

## Lab 4 — Responsible AI Prompt Library

Create and test prompts for meeting summaries, executive briefings, structured correspondence, risk extraction and process documentation.

**Evidence:** prompt, test input, output, verification notes, privacy classification and limitations.

## Lab 5 — Controlled Approval Workflow

Design a low-code workflow using synthetic data. Include trigger, approval, conditions, notifications, error handling, permissions, audit and rollback.

**Evidence:** diagram, prototype, test cases, exception log and user guide.

## Lab 6 — Executive Dashboard

Use Power BI, Looker Studio or an approved equivalent to create a dashboard for operational workload, service performance, budget variance or action closure.

**Evidence:** clean dataset, KPI dictionary, dashboard and one-page executive commentary.

## Lab 7 — Digital Workplace Standard

Design a controlled team workspace covering naming, folder structure, ownership, access, versioning, meeting records, retention and offboarding.

**Evidence:** architecture diagram, governance standard and adoption checklist.

## Lab 8 — Privacy and Responsible-AI Review

Assess one workflow or dashboard for lawful purpose, data minimisation, access, retention, human oversight, vendor risk and incident response.

**Evidence:** review checklist, risks, actions, owners and due dates.

## Assignment submission standard

- Use synthetic or expressly authorised data.
- Add a README describing the problem, method, controls, result, limitations and next step.
- Include screenshots only after removing confidential details.
- State whether the output is a simulation, prototype or production implementation.
- Record mentor feedback and resulting changes.
