# Credential and Badge Targets

Credential names and availability must be confirmed before enrolment. A formal exam is optional when a current learning path and assessed project provide better evidence.

| Priority | Target milestone | Purpose | Timing |
|---|---|---|---|
| Core | Enterprise Design Thinking Practitioner or equivalent | Problem framing, stakeholder empathy and outcome design. | Weeks 1–4 |
| Core | AI fundamentals and responsible-use milestone | AI concepts, verification, ethics and governance. | Weeks 4–6 |
| Core | Advanced Excel / spreadsheet analytics milestone | Validate analytical capability beyond general Office use. | Weeks 2–8 |
| Core | Power BI or equivalent visualisation milestone | Dashboard development and operational storytelling. | Weeks 6–10 |
| Core | Power Automate / workflow automation applied milestone | Build and govern a workflow. | Weeks 6–12 |
| Core | Project management fundamentals milestone | Planning, risk, stakeholders and delivery cadence. | Months 1–4 |
| Supporting | Microsoft 365 or Google Workspace pathway | Digital workplace governance and collaboration design. | Months 2–5 |
| Supporting | Privacy, security and responsible-AI awareness | Compliant operational technology use. | Months 2–6 |
| Stretch | Power Platform fundamentals readiness | Recognisable low-code foundation. | Months 4–9 |
| Stretch | Business analysis or process-improvement readiness | Transition into analyst, transformation or operations-improvement roles. | Months 7–12 |

## Credential acceptance gate

A credential counts toward the IDR only when Fernanda can:

- explain the underlying capability;
- demonstrate it in a practical task;
- connect it to a target role;
- provide an evidence link or certificate record; and
- document one next step for deeper application.

Use the dashboard workspace to track completion and retain certificate files in an approved private evidence store.
