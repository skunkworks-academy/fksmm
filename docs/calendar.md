## Google Calendar

1. Open Google Calendar in a desktop browser.
2. Select **Other calendars → + → From URL**.
3. Paste the HTTPS subscription URL.
4. Select **Add calendar**.

## Outlook

1. Open Outlook Calendar.
2. Select **Add calendar → Subscribe from web**.
3. Paste the HTTPS subscription URL.
4. Name it **Fernanda IDR — 12 Week Sprint** and save.
